# Batch 4: meeting notes

**For:** collections of meeting notes or minutes, where the useful questions are "what did we decide
about…?", "who owns…?" and "what's still open?".

**Overrides:**
- `sp_NoD.txt`: the default plus a "Focus for meeting notes" section: decisions, action items and
  meetings become items, and owners and due dates are kept in their contexts.
- `sp_ADHD.txt`: the default plus tags for state ("Open Action", "Completed Action"), "Recorded
  Decision", and the role people play in the notes ("Action Owner", "Decision Maker").

**Questions that work well afterwards:** "What decisions were made about the launch?", "What
actions does Maria Lopez own?", "Which action items are still open?"

**Use:** a separate folder for meeting notes. Set `LUM_PROMPTS_DIR` to it while adding meeting notes,
then set it back (or empty it) before adding other kinds of documents.
